# 09 · 被删条目（22 篇虚假/无法核实文献）的正文处理审计

> 本文回答一个问题：**那 22 篇被彻底删除的文献，正文里引用它们的内容是怎么处理的？**
> —— 换了别的真实文献？还是把内容一起删了？
>
> 审计方法、原始证据与逐条判定见下。全部结论均可复现（见 §6 复现脚本）。

## 0 · 一句话结论

**没有"因为文献删了就把整段内容删掉"的情况。**

- **26 个引用点**中，**14 处（54%）换挂了真实文献**，技术论断原样保留；
- **10 处（38%）保留论断、去掉具名**（"X et al. 提出……" → "……被提出"），且多数仍挂着**未被删除的真实支撑文献**（如 `rossi2020temporal`、`hinton2015distilling`、`cho2014learning`）；
- **只有 2 处（8%）真正删掉了文字**：一处删了一个状语从句，一处从一个四人并列名单里删掉了一项。

按用户决策 #2 **"保留技术论断但去具名"**，正文的**信息密度基本不变**，减少的是**虚假的归属**（谁提出的）而不是**技术事实**（提出了什么）。

## 1 · 审计口径的建立

### 1.1 先确定"被删且被引用"的条目数

以 `.aux` 的 `\citation{}`（bibtex 真正看到的输入）为权威口径：

```
旧 is26.aux 引用 key : 222
新 is26.aux 引用 key : 199
```

对账：

```
  旧 222
  − 被删且被引 26   ← 本轮审计对象
  + 新增且被引  3   （frino2018macroeconomic, richter2024survey, wang2024mtsisurvey）
  = 199            ✓ 与 .bbl bibitem 实测一致
```

这 **26 个 key** 又分成两半：

| 组 | 数量 | 含义 | 正文处理 |
|---|---:|---|---|
| **A 组** | 4 | **同一篇文献换 key**，论文仍在库中、仍被引用 | key 替换，正文无实质变化 |
| **B 组** | 22 | **论文已不在库中**（虚假/无法核实） | ← **本文审计对象** |

A 组 4 条（仅记录，不属本文范围）：

```
Time-LLM         → jin2024timellm
aksu2024gifteval → GIFT-Eval
box1970          → box2015time
qiu2024tfb       → TFB
```

### 1.2 ⚠️ 第一次审计失败的原因（已修正）

初次审计用朴素正则 `\\cite...\{[^}]*\bKEY\b[^}]*\}` 扫描旧正文，**22 条全部报"0 处引用"**。原因是**嵌套花括号**：

- 仓库 `e7fa6b0` 的 `sections/` 里有 **802 处** `\revadd{}` / `\revdel{}` 第二轮修订标记；
- 这些标记常常**嵌在 `\cite{}` 参数内部**：
  ```latex
  \cite{\revadddec{Zhang et al.~}\citep{zhang2023imputation} ...}
  ```
- `[^}]*` 在内层 `\citep{...}` 的第一个 `}` 处就截断了，永远匹配不到目标 key。

**修正做法（三步）：**

1. 用 `/tmp/strip.py` 按**花括号配对**先剥掉 `revadd/revdel` 等标记，得到"净正文"；
2. 在净正文上用**括号配对提取器**解析 `\cite*{k1,k2,...}` 参数列表；
3. 定位 key 所在的**整句**，再在新版同文件的句子里做 `difflib.SequenceMatcher` 对齐，人工判读差异。

修正后：**旧正文 26 处引用点全部定位成功，新正文残留 0 处。** ✅
