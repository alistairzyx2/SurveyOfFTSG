
## 5 · 生成新标记稿

```bash
./redline.sh
```

- 基准默认 `aa33670`（可传参覆盖，如 `./redline.sh e7fa6b0`）
- 需要 `latexdiff`；若未安装会打印安装指引

```bash
# 未安装时
brew install latexdiff
```

脚本会：
1. 从 git 导出基准快照到 `/tmp/redline_XXXX/old`
2. 镜像当前 `main_clean/` 到 `new`
3. 把两侧 `\input{}` 内联为单文件
4. 跑 `latexdiff --type=UNDERLINE`
5. 后处理（修补表格/公式环境内的 DIF 宏冲突）
6. 写入 `main_clean/is26_redline.tex` 并编译

## 9 · 回滚

### 文件级（保留提交历史）
```bash

```

### git 级（丢弃提交）
```bash
./rollback.sh --git       # 交互式 git reset --hard aa33670
```

### 手动全量回滚
```bash
cd "$REPO"
git reset --hard aa33670
git clean -fd
git --no-pager log -1
```

> ⚠️ 若**已经 push** 过，回滚需要 `git revert` 而非 `reset`：
> ```bash
> git revert --no-edit <坏提交>
> git push origin main
> ```

## 11 · 若出问题

| 症状 | 原因 | 处置 |
|---|---|---|
| `bibitem count` 不是 199 | bib 与 sections 未配对 | `./rollback.sh --files` 后重跑 `--apply` |
| PDF 里有 `[?]` | 同上 | 同上 |
| `undefined citations` > 0 | 同上 | 同上 |
| `11_conclusion.tex` 消失 | 误删 | 从备份 `root/sections/` 还原 |
| `git 工作树干净` 为 ✗ | 仓库有未提交改动 | `git stash` 或先提交 |
| `latexdiff` 未找到 | 未安装 | `brew install latexdiff` |
| 编译报 `forest.sty` 找不到 | `TEXMFHOME` 缺 `inlinedef.sty` | 已装在 `~/Library/texmf`，检查 `kpsewhich inlinedef.sty` |
| `merge.sh --apply` 报权限错 | 目标只读 | 检查 `/Volumes/FunkDisk` 挂载未变只读 |

**任何异常 → `./rollback.sh --list` 先看回滚点，不要手改文件。**
